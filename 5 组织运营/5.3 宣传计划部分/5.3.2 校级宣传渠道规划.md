# 5.3.2 校级宣传渠道规划

## 渠道建联

九霄战队已与澳门理工大学官方微信公众号的负责老师取得联系。宣运组负责撰写新闻稿、整理照片和视频，由指导老师统一向校方负责人提交。每场赛事前，宣运组拟通过指导老师确认选题、素材要求和投稿时间。后续拟拓展的校级或院级渠道待确认。

## 内容合作

校媒较关注赛事成绩与荣誉。赛后稿件将优先写明赛事全称、组别和经核实的成绩，再选取一个与比赛有关的备赛细节，说明队员遇到了什么问题、如何协作解决。配图优先选用有简短说明的赛场照片、机器人实拍和队伍合影，方便校方编辑选用。

## 赛季关键节点

| 节点 | 拟与校媒开展的工作 |
| --- | --- |
| 赛季启动 | 通过指导老师向校方负责人介绍本赛季参赛计划，结合往届东北站 3V3 十六强的经历，沟通值得跟进的选题。 |
| 赛前出征 | 提交出征简讯、参赛队伍合照及机器人实拍，邀请学校公众号预告赛事，并提前约定赛后供稿时间。 |
| 赛后成绩公布 | 核实成绩后提交赛事新闻稿，附官方成绩依据、现场照片和队员感言，争取在学校公众号刊发赛季重点报道。 |

全年目标为至少完成一次校级媒体正式刊发。宣运组将记录每次投稿的日期、渠道、主题和刊发状态，并保存已发布报道的标题与链接，供赛季复盘和下届交接使用。
